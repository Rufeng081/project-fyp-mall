# Test Result Notes

This folder is reserved for testing and performance-evaluation material.

Use:

- `reports/` for written JMeter plan, execution, and evaluation records.
- `records/` for chronological test-execution evidence.
- `results/` for retained metrics and charts.
- `jmeter-plans/` for the executable JMeter scenario definitions.

The copied result set intentionally excludes generated JMeter HTML report folders because those contain many report dependencies and third-party assets. The retained CSV, Markdown table, SVG charts, execution record, and evaluation report are the canonical thesis evidence.
